# 横琴天数小工具隐私政策

更新日期：2026 年 10 月 20 日；当前版本：2.25.0。

本扩展用于统计用户在珠海横琴的驻留天数，并提供日历、手动标记、假期桥接、目标预测及定位诊断日志。

## 当前版本处理哪些数据

取得浏览器定位授权后，扩展会在启动、后台定时检查或打开弹窗时，通过浏览器 Geolocation API 取得设备经纬度、定位时间及定位精度。扩展在本机根据横琴中心 8 公里范围计算是否驻留，保存每日驻留状态、手动标记、请假及定位错误信息。

2.25.0 已移除城市解析能力及外部接口主机权限，不再通过扩展代码调用城市解析服务，不再向 BigDataCloud 发送经纬度，也不再生成或导出城市列表。浏览器或操作系统自身定位服务的数据处理由相应提供方负责。

扩展不读取浏览网页内容或浏览历史，不要求提交姓名、邮箱、支付信息或账户密码。

## 数据存储、同步与用途

每日状态及统计设置通过 chrome.storage.sync 保存，并可按用户的浏览器同步设置跨设备同步；原始坐标、定位时间、定位精度及错误日志保存在当前设备的 chrome.storage.local 中。开发者没有自建服务器接收这些数据。

本扩展不出售用户数据，不将数据用于广告、信用评估或贷款决定，也不加载或执行远程 JavaScript/Wasm。周末按桥接规则统计，定位城市不参与计算。

## 控制、导出与删除

用户可以通过浏览器或操作系统关闭定位权限，也可停用或卸载扩展。定位失败或权限关闭时自动统计可能不完整，用户可手动标记。

用户可自行导出备份和调试日志，并选择是否分享。调试日志包含精确坐标，请在分享前检查并自行保管。扩展未设置自动清理历史定位日志的期限。卸载扩展可删除本机扩展存储；同步数据的保留及删除由 Chrome/Google 的同步机制和账号设置管理，已导出或自行分享的副本须单独删除。

## 旧版本说明

2.24.0 曾将设备本次定位经纬度通过 HTTPS 发送到 api.bigdatacloud.net，以取得中文城市名；服务也会收到请求 IP 地址等网络信息。根据服务官方说明，其免费客户端服务会匿名汇总坐标与 IP 配对信息以改进 IP 地理定位数据，处理及保留安排由其隐私政策管理。服务说明：https://www.bigdatacloud.com/docs/article/why-is-reverse-geocoding-api-free 。

该能力自 2.25.0 起已移除。旧版本写入的城市数据可能仍保存在本机，但当前版本不再读取、更新或导出这些城市列表。本政策不表示历史上已传输给第三方的数据已经被删除。
